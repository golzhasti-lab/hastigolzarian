# Git و GitHub

## Git چیست؟

Git سیستم کنترل نسخه است که برای مدیریت تغییرات پروژه استفاده میشه

## GitHub چیست؟

GitHub یک سرویس آنلاین برای ذخیره و مدیریت و به اشتراک‌ گذاری پروژه‌های Git هست

## تفاوت Git و GitHub

Git یک ابزار برای مدیریت تغییرات پروژست اما GitHubیک سرویس آنلاین برای نگهداری و اشتراک‌ گذاری پروژه‌هاس
