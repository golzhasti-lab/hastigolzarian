# Exercise 5 - GET and POST

## GET چیست؟

GET یکی از متدهای HTTP است که معمولاً برای دریافت اطلاعات از Server استفاده می‌شود.

### Example

```http
GET /products
```

این درخواست برای دریافت لیست محصولات استفاده می‌شود.

## POST چیست؟

POST یکی از متدهای HTTP است که معمولاً برای ارسال اطلاعات به Server استفاده می‌شود.

### Example

```http
POST /users
```

## تفاوت GET و POST

| GET                                        | POST                                      |
| ------------------------------------------ | ----------------------------------------- |
| معمولاً برای دریافت اطلاعات استفاده می‌شود |               معمولاً برای ارسال اطلاعات استفاده می‌شود |
| پارامترها معمولاً در URL قرار می‌گیرند     |             اطلاعات معمولاً در Body قرار می‌گیرند     |
| برای دریافت و جستجوی اطلاعات مناسب است     |                برای ایجاد یا ارسال اطلاعات مناسب است     |
| معمولاً باعث تغییر اطلاعات Server نمی‌شود  | می‌تواند باعث ایجاد یا تغییر اطلاعات شود  |

## چه زمانی از GET استفاده می‌کنیم؟

زمانی که می‌خواهیم اطلاعاتی را از Server دریافت کنیم.

### مثال واقعی

```http
GET https://api.example.com/users
```

این درخواست برای دریافت اطلاعات کاربران استفاده می‌شود.

## چه زمانی از POST استفاده می‌کنیم؟

زمانی که می‌خواهیم اطلاعاتی را به Server ارسال کنیم؛ برای مثال ایجاد یک کاربر جدید.

### مثال واقعی

```http
POST https://api.example.com/users
```

اطلاعات کاربر می‌تواند در Body درخواست قرار بگیرد:

```json
{
  "name": "Ali",
  "email": "ali@example.com"
}
```
