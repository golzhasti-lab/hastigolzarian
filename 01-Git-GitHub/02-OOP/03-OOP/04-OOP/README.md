# Exercise 4 - URL

## URL چیست؟

URL مخفف **Uniform Resource Locator** است و آدرس یک منبع در اینترنت را مشخص می‌کند.

## Example

```text
https://www.example.com/products?id=25
```

## قسمت‌های مختلف URL

```text
https://       → Protocol
www            → Subdomain
example.com    → Domain
/products      → Path
?id=25         → Query Parameter
```

بنابراین:

* **Protocol:** `https`
* **Subdomain:** `www`
* **Domain:** `example.com`
* **Path:** `/products`
* **Query Parameter:** `id=25`
