# Exercise 3 - HTTP and HTTPS

## HTTP چیست؟

HTTP مخفف **HyperText Transfer Protocol** است و برای انتقال اطلاعات بین Client و Server در وب استفاده می‌شود.

## HTTPS چیست؟

HTTPS مخفف **HyperText Transfer Protocol Secure** است و نسخه امن HTTP محسوب می‌شود. HTTPS با استفاده از رمزنگاری TLS، ارتباط بین Client و Server را امن‌تر می‌کند.

## تفاوت HTTP و HTTPS

* HTTP ارتباط را بدون رمزنگاری TLS انجام می‌دهد.
* HTTPS ارتباط را به صورت رمزنگاری‌شده انجام می‌دهد.
* HTTPS امنیت بیشتری نسبت به HTTP دارد.
* HTTPS از اطلاعات حساس کاربران در هنگام انتقال محافظت می‌کند.

## چرا بیشتر وب‌سایت‌ها از HTTPS استفاده می‌کنند؟

زیرا HTTPS باعث افزایش امنیت ارتباط بین کاربر و Server می‌شود و از اطلاعاتی مانند رمز عبور و اطلاعات حساب کاربری در هنگام انتقال محافظت می‌کند.
